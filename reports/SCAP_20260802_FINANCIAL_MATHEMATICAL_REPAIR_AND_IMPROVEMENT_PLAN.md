## 1. 最终方向

本次不能通过简单降低经济门槛、提高目标仓位或固定增加持股数量解决。正确方向是建立一个“数据取得交易权—净收益与费用—联合尾部风险—动态持仓数量—整数执行—成交复核”的闭环。

保留现有合理原则：

1. 退出模块保留；评价退出要使用退出后的反事实损失节省，不能把退出时已经发生的亏损当成退出模块造成的亏损。
2. 不使用大盘牛熊二元总开关。市场状态只允许连续、有限幅度地调整风险预算、收益先验和新增风险，不得一键关闭全部交易。
3. 允许现金。没有成本后正期望机会时，空仓是合法最优解。
4. 不设置永久5只或13只金融硬上限。Web可以给用户硬上限；未填写时，由现金、整手、费用、单名风险、相关性和边际收益内生决定实际持仓数。

必须纠正的核心：

- `execution_runtime.py`不能再把ActionPlan的多手目标覆盖为一手。
- 因子列存在不等于因子可交易；每个取得交易权的角色必须逐日具有足够非空、非过期的PIT证据。
- 当前所谓组合CVaR是单股CVaR的常相关平方根聚合，只能叫`correlated_tail_loss_proxy`；正式CVaR必须从联合情景的组合损失分布计算。
- 74个因子不能等价为74份独立证据。严格入口6因子全部属于规模家族时，模型必须按有效独立家族而不是原始列数计置信度。

## 2. 主金融数学模型

### 2.1 状态与决策变量

对股票`i`：

- 当前股数：`h_i`
- 每手股数：`L_i`
- 目标手数：`x_i ∈ {0,1,...,x_i,max}`
- 目标股数：`H_i = L_i x_i`，已有碎股仅在退出腿单独处理
- 交易增量：`ΔH_i = H_i - h_i`

新开、加仓、减仓、退出统一表示为“当前股数到目标股数”，同一股票只能有一个最终目标，避免多个proposal互相叠加。

### 2.2 精确自融资约束

所有现金使用最终订单股数逐腿计算：

`cash_after = cash_before + Σ sell_net_proceeds_i(-ΔH_i) - Σ buy_cash_required_i(ΔH_i)`

约束：

`cash_after >= cash_buffer(NAV)`

其中：

- 买入现金=`成交名义金额 + 买侧佣金 + 买侧规费 + 滑点/冲击`
- 卖出净回款=`成交名义金额 - 卖侧佣金 - 印花税 - 卖侧规费 - 滑点/冲击`
- 最低佣金按每张真实订单触发，不能先按一手算后乘手数。
- 费用profile必须由计划、执行、成交、报表共用同一个不可变身份；券商最低佣金是账户合同参数，不应写死为市场规则。

### 2.3 相对不交易基线的联合情景财富

定义`hold`为不新增交易、保留当前合法持仓的0元增量基线。对未来统一期限`H`和联合市场情景`s`：

`ΔW_s(x) = W_s(target x) - W_s(hold) - incremental_trade_cost_s(x)`

情景必须保留同一天各股票的横截面相关性；压力情景还要保留涨跌停、停牌、跳空和无法成交。不能把每只股票独立抽样后再人为假定相关系数。

建议主期限使用现有可校准的10日；5日和20日只作敏感性分析。收益预测、预测误差、费用、CVaR和反事实都必须使用同一预测期限。

### 2.4 收益、赔率与“盈利覆盖亏损”

对每只股票，使用决策日前滚动校准样本估计：

- `p_i`：成本后盈利概率
- `G_i`：盈利条件下平均成本后盈利金额
- `L_i`：亏损条件下平均损失金额的绝对值
- `C_i(q)`：最终手数下的完整生命周期增量费用

点期望：

`EV_i(q) = p_i G_i(q) - (1-p_i)L_i(q) - C_i(q)`

盈亏覆盖比：

`PCR_i(q) = p_i G_i(q) / ((1-p_i)L_i(q) + C_i(q))`

盈亏平衡胜率：

`p_break_even = (L_i + C_i) / (G_i + L_i)`

这里正面回应“单只盈利能覆盖多少亏损”：不能只看胜率，也不能只看一次最大盈利；必须同时看胜率、平均盈利、平均亏损和最终订单费用。成熟证据下应要求稳健下界`PCR_LCB > 1`；冷启动阶段不做伪精确硬判定，而是向市场/家族先验收缩并降低最大下注。

所有`p/G/L`按以下层级收缩：股票 → 论点/因子家族 → 板块/流动性桶 → 全市场先验。有效样本量按相关性折扣，6个高度相关的规模因子不能贡献6倍置信度。

### 2.5 正式组合CVaR

对损失`Z_s(x)=-ΔW_s(x)`，正式95% CVaR/ES为：

`CVaR_95(x) = min_eta [eta + 1/(0.05 S) Σ_s max(Z_s(x)-eta,0)]`

推荐采用硬风险预算而不是多重软罚金：

`CVaR_95(x) <= B_ES(NAV, drawdown_state, evidence_state)`

在风险预算内最大化稳健增量财富：

`maximize RobustCE(x) = E[ΔW_s(x)] - model_uncertainty(x)`

如果业务确需风险厌恶排序，只允许增加一个人民币单位的`λ×CVaR`项；不得再同时叠加相关罚金、固定downside罚金、thesis风险罚金和压力罚金来重复惩罚同一种尾部风险。

当前常相关平方根聚合可在联合情景不足时保留，但必须：

- 改名为`correlated_tail_loss_proxy`；
- `risk_model_used`不得写`scenario_cvar`；
- 只能降低风险预算或作为硬上界，不能伪装成已校准正式CVaR。

### 2.6 目标函数与词典序

建议采用以下词典序，减少任意罚分权重：

1. 执行必须退出的安全订单；
2. 满足T+1、停牌、涨跌停、现金、Web硬上限、单名风险和组合ES硬约束；
3. 在可行计划中最大化稳健成本后人民币增量财富；
4. 目标接近时选择费用更低、ES更低、有效独立家族更高的计划；
5. 最后才参考部署率和持仓广度。

部署不足不能把负期望交易变成正期望交易；广度奖励不能绕过费用和风险门。

## 3. 动态持仓数量模型

### 3.1 分离四个K

- `K_web`：用户可选硬上限；空值表示不施加用户硬上限。
- `K_feasible`：现金、整手、费用、数据、交易规则和单名风险共同决定的可行上限。
- `K_search`：求解器资源上限，只是工程参数。
- `K_selected`：优化器最终选择的正边际价值持仓数。

必须满足：

`K_selected <= min(K_web if set, K_feasible, K_search)`

但这只是上界；优化器可以选择更少，也可以在NAV增长、候选改善后选择更多。

### 3.2 K_feasible不能只由最低订单金额决定

每一个候选的一手或多手增量必须同时满足：

1. 最终订单的往返费用率；
2. 稳健毛利润覆盖完整生命周期费用；
3. 单名计划损失预算；
4. 加入组合后的边际ES预算；
5. 精确累计现金；
6. 至少一个有效独立alpha家族支持。

因此`K_feasible`应通过逐候选可行性/优化器求得，而不是简单计算`NAV ÷ 最低经济订单`。低价股票多手可以摊薄最低佣金，高价高波动股票可能一手就超过风险预算。

### 3.3 内生K_selected

按边际价值加入第`k`只股票：

`MarginalCE_k = RobustCE(S_k) - RobustCE(S_{k-1})`

只有同时满足`MarginalCE_k>0`和组合ES约束时才增加持仓。这样NAV从2万增长后，持仓数会自然增加；若新增股票与现有小市值风格高度相关，即使现金足够也不会机械扩张。

建议报告而不硬编码以下指标：

- 有效持仓数：`N_eff = 1 / Σw_i²`
- 有效家族数：对家族风险权重计算同样的逆HHI
- `N_eff / K_selected`
- Top 20%股票的权重和风险贡献
- 删除最大1/3/5/10收益日后的终值

## 4. 针对2万元的参数确定方法

不能直接宣称某组参数最优。以下仅是校准边界和搜索方法：

### 4.1 现金与费用

- 现金缓冲候选：`max(1000元, 5% NAV)`与`max(1500元, 7.5% NAV)`。
- 费用阈值不再单独固定0.50%；以最终手数下`PCR_LCB>1`和`EV_LCB>0`为主门。
- 0.50%仅作为监控警报：若最终计划往返费用率高于0.50%，必须有更高的稳健毛利润覆盖，不得自动放行或自动拒绝。
- 滑点/冲击按成交额占该股历史可交易金额比例建模；缺少校准时采用保守分档，不得固定为0。

### 4.2 风险预算

研究候选范围，而非最终值：

- 单名压力损失预算：NAV的2.0%—3.0%。
- 组合10日ES预算：NAV的5%—8%。
- 正常新增风险暴露上限：80%—90%。
- 数据冷启动或联合情景不完整时：新增风险预算乘0.60—0.80，而不是把协方差填0。
- 回撤达到8%/12%/15%时，用连续函数逐步收缩新增ES预算；不做市场牛熊二元开关，也不强制卖出所有持仓。

选择标准是滚动样本外的中位数成本后对数增长、最差块ES、最大回撤和收益集中度，不能以本次338日总收益最高为标准。

### 4.3 市场状态

市场状态只能影响：

- 收益先验收缩强度；
- 允许的新增ES预算；
- 流动性/冲击压力；
- 利润保护的紧度。

建议有界连续调整，例如风险预算乘数限制在`[0.70,1.10]`，具体边界通过留出期校准。状态基准、绩效基准和市场宽度可以身份不同，但必须明确角色、都具有有效PIT数据，不能用缺失宽度固定回填0.5后声称使用了市场宽度。

## 5. 因子与收益模型提升

1. 严格入口从“6个规模列投票”改为“独立经济家族证据”。规模、质量、趋势、反转、流动性、波动/尾部、盈利预期分别先在家族内聚合，再在家族间组合。
2. 每日保存原始列数、有效列数、有效家族数、家族相关矩阵和有效独立证据数。
3. 相关系数接近1的因子只保留一个代表或通过正交/家族聚合降维；选择过程只能使用训练窗口。
4. 收益预测使用滚动PIT校准，输出点预测、标准误、样本量、漂移状态和收缩后预测。
5. `strict`与`proxy`交易权必须二选一写入运行身份：proxy若仅诊断，strict断流则全run预检失败或截断到共同有效日期；proxy若获交易权，必须独立校准并保存授权来源，不能静默替代。
6. 赢家加仓单独作为策略臂评估。当前6次样本不足且均值为负，修复阶段保持研究门关闭；只有滚动样本外的增量加仓相对不加仓反事实为正，才逐层开放。

## 6. 退出模型

退出模块保留，并改用反事实评价：

`saved_loss_H = value_if_held_to_H - value_after_exit_to_H`

需要同时报告：

- 退出后1/5/10/20日避免的损失或放弃的反弹；
- 卖出费用和无法成交影响；
- 相对“继续持有”而不是相对买入价的增量财富；
- 牛/中性/弱/熊及市场宽度分桶，但不据此启用二元总开关。

强制灾难退出是安全硬约束；signal/thesis/profit-giveback等普通退出应与hold比较成本后增量价值，不能因为已经亏损就否定退出，也不能因为退出后继续跌一次就永久确认模块有效。

## 7. 两个P0缺陷的修复合同

### 7.1 多手计划—执行守恒

必须逐层保存并验证：

`selected_target_lots × lot_size = action_target_shares = order_target_shares = pending_target_shares`

成交后：

`filled_shares + remaining_shares = requested_increment_shares`

若部分成交，剩余股数必须显式取消或进入下一合法执行日；不得写`action_plan_unchanged`。计划费用、风险和经济门要以最终实际请求股数复算；数量改变超过容忍时，原计划失效并重新授权。

### 7.2 因子交易权时效

启动前计算每个交易角色的：

- 最小/最大有效日期；
- 每日非空覆盖率；
- 每日有效横截面数量；
- 数据年龄；
- PIT状态和来源哈希。

任一交易授权角色在窗口内中断时：

- 正式研究run：启动前fail closed；或
- 明确把结束日期截断为所有授权数据的共同最大有效日期。

不得运行到末尾后把连续NaN解释成市场没有机会。

- 修复后策略必须与简单等权、风险等额和现金基准做样本外比较。

### 研究门

- 不能只看总收益。必须同时披露几何相对收益、最差块、最大回撤、ES、换手、费用、有效K和收益集中度。
- 最大5日贡献、删除最大10日收益、峰值恢复时间不能恶化到无法接受而被总收益掩盖。
- DSR/PBO/SPA不再是`insufficient`；未达到预先登记阈值则保持研究状态。
- 20日工程通过不等于可上线；长窗口、滚动样本外和正式PIT仍是上线前置条件。

## 11. 外部研究依据

- Rockafellar与Uryasev：CVaR应由损失尾部及其优化表示定义，适合作为组合尾部风险目标或约束。
- Lobo、Fazel与Boyd：固定费用会使组合优化成为非凸/混合整数问题，交易成本必须与持仓和风险共同进入优化。
- Ledoit与Wolf：高维样本协方差估计误差很大，需要收缩，优化器会放大极端估计误差。
- DeMiguel、Garlappi与Uppal：复杂优化样本外未必稳定胜过1/N，因此本模型必须保留简单基准和样本外比较。
- Bailey与López de Prado及后续PBO研究：Sharpe需要校正非正态、多次试验和选择偏差；本次收益具有厚尾且依赖少数大涨日，不能只报告普通Sharpe。

## 12. 最终判断

最优先不是继续调高持仓数量，而是先恢复“计划就是实际执行”和“交易权数据在整个窗口真实有效”。在此基础上，用最终手数下的真实费用、收缩后的盈利/亏损赔率、联合情景ES和正边际价值内生决定持仓数。

这套方案不会保证曲线平滑，也不应追求平滑。它的目标是让少数真实涨停仍能贡献凸性收益，同时避免收益完全依赖单一小市值家族、错误缩手或数据断流；并使每一次买入、退出、加仓、持有现金都能用同一人民币反事实模型解释和复算。
