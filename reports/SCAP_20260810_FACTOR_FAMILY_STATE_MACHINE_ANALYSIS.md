## 1. 结论先行

用户提出“不同因子族群代表不同市场信号，简单共同打分会模糊金融概念”，方向正确。需要修正的一点是：不应为 74 个原始因子分别创建 74 台交易状态机，而应按可解释、可验证的**经济论点（thesis）**建立少量状态机，例如反转、趋势、突破、基本面重估、低波防御。流动性、风险、成本、PIT 完整性不是与这些论点并列的收益因子，而应作为正交门控。

当前系统已经不是最原始的等权平均：它先做截面排名、近亲/高相关因子压缩、家族中位数、角色平衡，并将缺失覆盖率向 0.5 收缩。但是“数学上去重复”不等于“金融语义已分离”。当前仍存在严格入场权几乎等同小盘风格、入场标签与真实得分权威不一致、流动性方向疑似反置、时间尺度错配等问题。因此下一步重点不应是再加权，而应是修复语义合同、论点血缘和状态机权限。

## 3. 各因子族群：公式、金融逻辑与误用风险

### 3.1 规模风格（Size）

- 公式：`size_float_neg = -log(1 + float_market_cap)`；总市值版本同理。数值越高代表市值越小。
- 金融逻辑：小公司可能具有成长弹性、信息覆盖不足和风险补偿，也更容易受到小盘风格行情推动。
- 风险：小盘并非天然“质量好”，其流动性、涨跌停、壳价值、退市和拥挤风险更高。它应主要用于股票池、风格预算和容量限制，不适合作为唯一严格买入论点。
- 当前问题：6 个 `entry_alpha` 全部来自规模家族，所以系统的严格 alpha 实质上是“小盘倾向”。

### 3.2 价值（Value）

- 账面市值比：`book_to_price = total_equity / market_cap`。
- 自由现金流收益率：`fcf_yield = (operating_cash_flow_TTM - capex_TTM) / market_cap`。
- 金融逻辑：以较低价格购买可验证的资产或现金流，等待估值回归。
- 风险：便宜可能来自盈利恶化、资产虚高或行业衰退，即“价值陷阱”。必须与现金流质量、资产质量和催化剂联合，不能只看便宜。

### 3.3 成长（Growth）

- 公式：`growth_surprise = current_revenue_yoy - mean(previous_observed_revenue_yoy)`，当前实现至少要求 5 个历史观测。
- 金融逻辑：经营增速超出公司自身常态，可能触发盈利预期上修和重新定价。
- 风险：高增长若已被高估值充分计价，仍可能下跌；财报低频且有披露滞后，必须使用 PIT 可得日，不能用后来修订数据回填。

### 3.4 现金流质量（Cash-flow quality）

- 公式：`accruals_neg = -(net_profit_TTM - operating_cash_flow_TTM) / average_assets`。
- 金融逻辑：利润由经营现金流支持时通常更可靠；高应计利润可能反映收入确认激进或盈利质量较弱。
- 用法：更适合作为价值/成长论点的真实性门控，而不是日线买点。

### 3.5 反转（Reversal）

- 公式：`ret_n = P_t / P_(t-n) - 1`；`rev_n = -ret_n`。
- 金融逻辑：短期过度反应、流动性冲击、止损踩踏或行为偏差之后发生均值回归。
- 风险：下跌也可能是基本面信息被逐步定价；仅凭“跌得多”容易接飞刀。应要求止跌、超卖恢复、成交结构改善和时间止损。

### 3.6 动量（Momentum）

- 公式：通常直接使用 `ret_n` 或其截面排名；数值越高代表过去一段更强。
- 金融逻辑：信息扩散缓慢、资金持续流入、机构调仓和趋势跟随会产生延续。
- 风险：拥挤交易和市场急转时会发生 momentum crash。短期 5 日冲高与中期 3–12 月趋势也不是同一种动量，必须按时间尺度拆分。

### 3.7 突破（Breakout）

- 公式：`(close - prior_n_high) / (prior_n_high - prior_n_low)`。
- 金融逻辑：价格突破旧区间意味着供给被消化、新信息或资金需求可能主导。
- 风险：缩量突破或收盘无法站稳容易形成假突破，需要成交、收盘位置、流动性和回踩确认。

### 3.8 波动率（Volatility）

- 总波动：`vol_neg_n = -std(ret_1, n)`。
- 下行波动：`downvol_neg_n = -std(min(ret_1, 0), n)`。
- 金融逻辑：低波动/低下行波动可能获得更好的风险调整收益，弱市中尤其具有防御意义。
- 风险：低历史波动不等于低未来风险；停牌、价格钉住或事件前平静也会产生“假低波”。它更适合风险预算和防御论点，不应与收益 alpha 无差别相加。

### 3.9 流动性（Liquidity）

- Amihud：`amihud = abs(ret_1) / amount`；当前因子为 `amihud_neg_n = -mean(amihud, n)`，越高代表价格冲击越小、流动性越好。
- 两种不同金融含义：一是“执行流动性”，越好越可交易；二是“非流动性溢价”，越差可能要求更高预期收益，但必须支付更高成本和容量惩罚。这两者不能共用同一个 `liquidity_health` 名称和方向。
- 当前风险：柜中多个 `rank_gate_lo(amihud_neg)` 会选择低排名，即更差流动性，但下游又把它称作健康度，存在方向/语义错配的高置信嫌疑。

### 3.10 RSI 时机

- 恢复：`I(RSI_(t-1)<=35, RSI_t>RSI_(t-1), RSI_t>=30) * (RSI_t-RSI_(t-1))/100`。
- 过热：`-max(RSI-75, 0)/25`，0 表示未过热，越负表示越过热。
- 金融逻辑：识别超卖恢复或过热，而不是公司长期价值。
- 用法：适合作为反转/动量论点的阶段条件，不应单独承担长期收益预测。

### 3.11 日线订单流近似（Order flow proxy）

- 公式：`intraday_direction = ((close-low) - (high-close)) / (high-low)`；`flow_intensity = log(1 + amount/MA20(amount))`；二者相乘。
- 金融逻辑：放量且收在日内高位近似需求占优，放量收在低位近似派发。
- 边界：这不是 Level-2 主动买卖盘，只是 OHLCV 代理，容易受涨跌停、集合竞价和大宗交易影响。
- 当前风险：因子柜把该因子和 `turtle_breakout` 标为 `lower_better`，而公式和金融含义通常要求越高越好；运行会将其取负再排名，属于必须用方向真值表和构造样本验证的合同问题。

## 4. 当前评分并非简单平均，但为何仍然模糊

当前核心流程为：

1. 每个因子做当日截面百分位排名；
2. 同角色内，语义近亲或绝对 Spearman 相关不低于 0.90 的因子合并为经验簇；
3. 每个经济家族取经验簇中位数；
4. 角色分数按家族平衡，单家族份额最多 25%，缺失覆盖向 0.5 收缩；
5. 严格与代理入场按覆盖权威合成；时机调整和流动性惩罚后得到最终分数。

关键公式为：

`base_entry = (strict*strict_coverage + proxy*(1-strict_coverage)*proxy_coverage) / total_authority`

`final = clip(base_entry + timing_weight*(timing-0.5) - liquidity_penalty, 0, 1)`

默认 `strict_weight=1.0`、`timing_weight=0.0`。由此产生四个实质问题：

1. 严格覆盖充分时，价值、成长、反转和动量代理几乎没有排序权；最终分数主要是规模风格。
2. timing 默认权重为 0，名义上存在的时机角色通常不改变入场得分。
3. `risk_override` 中反转和动量占 11/16，收益机会与风险控制混在同一角色。
4. `cabinet_entry_thesis` 会从严格与代理家族中挑最高标签，却不检查其实际权威贡献。

20 日最终运行提供了直接例证：2026-03-09 的 `sh603282` 被标记为 `growth`，支持度 0.9774，但最终分数 0.617733 与严格规模分数完全相同，代理分数 0.7390 未取得实际权威；`sz301632` 被标为 `value`，但最终分数同样完全等于规模严格分数。也就是说，持仓生命周期可能锁定一个“没有真正驱动买入”的论点。这正是概念模糊，不只是权重是否平均的问题。

此外，74 个因子中 66 个记录的最佳检验期是 20 日，而角色却包含 1–5 日时机、风险和流动性控制。将 20 日有效的截面信号直接当作次日风险开关，属于时间尺度错配。

## 6. 推荐架构：市场状态机 + 论点状态机 + 正交门控

### 6.1 第一层：市场状态机

建议使用 `SHOCK / RISK_OFF / WEAK / NEUTRAL / RECOVERY / BULL`。它只决定：组合暴露上限、允许启动的论点、证据折扣和恢复速度。风险恶化可以快速，恢复必须滞回，避免一次反弹立刻满仓。市场基准应使用可投资、与股票池匹配且固定的 performance benchmark；风格、安全和机会集基准只作诊断，不得互相替代。

### 6.2 第二层：按经济论点建状态机

| 论点 | 状态路径 | 买入确认 | 退出/失效 |
|---|---|---|---|
| 反转 | `IDLE→OVERSOLD→STABILIZING→REBOUND_CONFIRMED→HOLD` | 超跌 + RSI/价格止跌 + 可执行流动性 | 再创新低、无跟随、时间止损、反弹回吐 |
| 动量 | `IDLE→EMERGING→CONFIRMED→MATURE→DECAY→BROKEN` | 中期相对强势 + 突破/量价确认 + 风险可接受 | 趋势破位、相对强度衰减、波动跃升、移动止盈 |
| 突破 | `SETUP→BREAKOUT→RETEST→CONTINUATION/FALSE_BREAK` | 越过旧高 + 收盘站稳 + 成交确认 | 回到突破位下、回踩失败、放量派发 |
| 价值/成长重估 | `UNVERIFIED→PIT_CONFIRMED→CATALYST→REPRICING→DETERIORATED` | PIT 基本面 + 现金流质量 + 催化剂/趋势确认 | 基本面恶化、估值回归完成、催化剂证伪 |
| 低波防御 | `STABLE→ELIGIBLE→HELD→VOL_SPIKE/EXIT` | 弱市/恢复期 + 稳定低下行波动 + 流动性合格 | 波动/beta 跃升、相关性失控、市场状态切换 |

### 6.3 第三层：正交门控

- 执行流动性：只判断是否能以合理冲击成交，不贡献 alpha。
- 风险：波动、beta、回撤、相关性和尾部风险，只限制尺寸或否决。
- 基本面质量：验证价值/成长，防止价值陷阱和伪增长。
- 成本与整手：佣金、印花税、滑点、涨跌停、T+1、现金和 100 股整手。
- 数据权威：PIT、样本量、漂移、OOS 范围和研究/交易权限。

### 6.4 组合不是相加，而是命名论点

- 中期动量 + 短期反转 = “上升趋势中的回调买入”，不是二者相互抵消后的中性。
- 反转 + 低波 = “有序超卖修复”；反转 + 高波 = “接崩盘”，风险完全不同。
- 突破 + 正订单流 + 高执行流动性 = “真实需求确认”；缺一项时可能是假突破。
- 价值 + 现金流质量 = “质量价值”；价值无质量 = “价值陷阱候选”。
- 成长 + 合理估值 = GARP；成长 + 极端估值应进入更严格的预期兑现状态。
- 小盘 + 动量 = “小盘趋势”，需要拥挤、涨跌停和容量预算；小盘 + 反转 = “微盘反弹”，执行风险更高。

冲突由组合仲裁器处理。例如趋势论点要求持有而反转论点认为已过热时，应比较各自状态、权威和退出后机会成本，而不是把 +0.8 与 -0.8 平均成 0。

## 7. 接口与血缘要求（实施前规格）

建议新增/收敛以下只读合同，先 shadow 双写：

- `FactorSemanticContract`：`factor_id, economic_family, role, direction, native_horizon, valid_regimes, unit, PIT_lag, authority_scope`。
- `ThesisEvidenceSnapshot`：每个论点的支持/反证、实际权威贡献、覆盖、样本、OOS 与成本后效用。
- `ThesisStateTransition`：`previous_state, event, next_state, guard_results, transition_reason, as_of_date`。
- `EntryThesisLock`：买入时只能锁定真正贡献最终决策权的论点，并保存贡献分解；标签不可仅取最高家族分。
- `ExitThesisDecision`：区分 thesis invalidation、风险退出、组合退出和执行失败。
- `PortfolioConflictDecision`：保存冲突论点、优先规则、否决原因与未选反事实。

Web 应展示市场状态轴、每只持仓的论点状态时间线、支持/反证证据、真实权威贡献、状态转移原因和退出来源；保持只读，不提供在线改权或应用阈值按钮。

1. 实现五类论点状态机、正交门控和冲突矩阵，但只写诊断账本。

3. Web 增加论点状态、转移原因和权威血缘，不允许在线切换交易权。

### 批次 C：严格证据与单变量消融

1. 同代码做 338 日 development shadow，再做不少于 504 日严格 PIT 全市场滚动 OOS。
2. 报告 `state × thesis × horizon` 的 Rank IC、ICIR、正 IC 比例、分位差、胜率、payoff、最大回撤、换手、费用、冲击和容量。
3. 先分别测试反转、动量、突破、基本面和低波状态机，再测试组合仲裁；禁止多模块同时开启后声称单变量提升。
4. 只有方向、样本、漂移、成本后收益、多重检验和留出期全部通过，才讨论有限交易权。

## 9. 最终判断

用户的思想不是“新手误解”，而是抓住了当前系统最关键的建模问题：**金融假设不能被一个无语义的总分替代**。专业化修正是：

1. 因子提供证据，不直接等于交易；
2. 经济论点拥有状态机，不是每个参数变体拥有状态机；
3. 市场状态决定论点权限和组合暴露；
4. 风险、流动性、成本和数据权威独立门控；
5. 买入时锁定真实驱动论点，卖出时检验同一个论点是否失效；
6. 所有动态适配先 shadow、后严格 OOS，不能根据已看过的回撤窗口反向调权。

当前研究门和生产门继续 `blocked`。本报告只形成可审查方案，不改变任何交易结果。
