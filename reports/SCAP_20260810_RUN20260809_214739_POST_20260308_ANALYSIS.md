# SCAP 2026-08-09/10 长窗口结果与 2026-03-08 后回撤归因

## 1. 审计边界

- 唯一主分析对象：`results/decision_council/scap/cab_c6dae8d4d69c/e4_l1200/v3/run20260809_214739`。
- 该 run 已完整保存，覆盖 2025-01-02 至 2026-05-29，共 338 个交易日；运行模式为 `small_capital_lean__cashok`、`aggressive_lean`、E4、-12% 灾难止损，固定 74 因子柜。
- 2026-03-08 是周日，不存在交易记录。局部事件以 2026-03-06、03-09 为观察起点，以 03-11 局部净值峰值为回撤基点。
- 对照对象仅使用同目录旧 338 日基线 `run20260804_221302`。代码身份不同，因此只用于解释容量修复前后的工程行为，不把收益差异当作严格单变量研究结论。

## 2. 结论先行

1. **容量—持仓修复没有“再次失效”**。新 run 的期末 NAV 为 26,495.55 元、总收益 +32.48%、最大回撤 -12.30%；旧基线分别为 24,946.33 元、+24.73%、-14.32%。平均实际暴露由 61.50% 降至 59.71%，平均持仓由 5.28 降至 4.92，但最终收益和回撤同时改善。
2. **3 月第一段下跌主要是市场冲击**。03-11 至 04-03，策略 -9.90%，研究基准 -10.19%，几何超额 +0.32%；不能把这一段全部归因于选股代码。
3. **4 月以后转为明显的策略相对失效**。04-01 至 05-29，策略 -1.99%，研究基准 +19.35%，几何超额 -17.88%；03-11 至期末的几何超额为 -17.14%。这不再能由市场下跌解释。
4. **直接机制是“弱势补买 + 早期失败无交易权限 + 风险恢复过快”叠加**。03-16 至 03-25 新买入四只股票的 10 日前瞻表现中，三只为负；系统已检测部分持仓的 `post_entry_failure`，但 `aggressive_lean` 主线明确把它从 active exit authority 中关闭，导致亏损继续扩大，直至更慢的 signal/loss containment 退出。
5. **研究证据不足以证明 2026 年各因子家族有效**。本 run 的 IC 时序只到 2025-03-31，而回测交易到 2026-05-29；`p_win_lower/avg_win/avg_loss` 在这些新买入上均为 0，校准状态为 `drifted`。因此不能引用整段 validation 汇总冒充 2026 年 3—5 月因子证据。
6. **本 run 不具备上线资格**。研究门为 `blocked`，关键失败包括 alpha 多样化、ECE 缺失、最新有效 N；统一研究门还被 failure lab、competing risk、multiple testing、PIT Level 1/2 和 impact calibration 阻断。

## 6. 退出权限和审计字段问题

`functions/decision_council/position_lifecycle.py` 第 925—934 行先生成 `post_entry_failure_signal`，随后对 mainline v3 且 control mode 不是 `aggressive_profit` 的运行把 `active_post_entry_failure=False`。本 run 为 `aggressive_lean`，因此早期失败仅是 paper observation，不进入 active arbitration。

实际样本：

- `sz301632` 在 03-12 起已多次出现 post-entry failure，03-23 浮亏约 -16.59%，直到 loss containment 才退出，最终约 -15.55%。
- `sz301129` 从 03-23 左右已处于约 -13.07% 且持续出现 post-entry failure，04-03 才由 `signal_failure_exit` 获得退出授权。
- 期末三只未平仓 `sz301170/sz001388/sz301227` 的浮亏约为 -12.35%/-11.24%/-8.98%，并均已出现 post-entry failure 观察。

另有一个独立审计语义缺陷：第 1259 行输出的 `post_entry_failure_exit` 使用原始 `post_entry_failure` 与 control flag，而不是 `active_post_entry_failure`。因此账本可能显示该字段为 True，但 `exit_authorized_reasons` 为空、仓位继续持有。该字段应拆成 detected / control-enabled / authority-active / veto-reason，避免 Web 和报告把 paper signal 当成真实退出授权。

## 7. 因子与市场状态能说什么、不能说什么

全样本 validation 汇总显示，5/10 日相对较强的模块包括 size、barra_size、conditional reversal/liquidity、conditional momentum/liquidity；5 日较弱的包括 volatility、range_grid、reversal_pullback、momentum-volatility。可是这些统计的 IC 时序仅有 2023-11-08 至 2025-03-31 的 7 个采样日，不能用来证明 2026-03—05 的状态适配。

现有 `governance_entry_payoff_by_regime.csv` 是执行后聚合，可描述 bull/neutral/weak 的历史结果，但没有把“因子家族 × 当时状态 × 严格 PIT × 滚动 OOS”的 IC/IR 和交易收益连起来。本次输出的 `governance_factor_layer_return_report.csv` 还是空状态产物。故当前不能有依据地回答“弱市应该永久换成哪一族因子”；最多只能形成待验证假设，不能直接授予交易权限。

## 8. 修复与实验优先级（尚未实施）

### P0：先修审计真实性

- 把 post-entry failure 拆为 `detected`、`paper_active`、`control_enabled`、`authority_active`、`blocked_reason`；Web 只把 `authority_active` 计入“退出数”。
- 对所有 detected 但未授权的持仓记录直到退出/期末的损失增量，形成真正的 counterfactual lag ledger。

### P1：单变量退出消融

- 保持日期、资本、因子柜、成本、PIT、仓位合同完全冻结，只比较 control 与“post-entry failure 受控授权”。
- 授权方案不能直接等同次日清仓：先以连续确认、最小持有期、相对安全代理恶化、可成交性约束构成状态机，再比较回撤、误杀反弹、profit factor 和换手成本。

### P2：市场状态恢复滞回

- 不修改安全硬上限，先做无交易权限 shadow：当 20 日收益仍负且 underwater 超过 8% 时，不允许单靠 5 日信号恢复到 normal deployment；要求长期状态连续修复后分阶梯恢复。
- 单独比较安全代理 sh510300、全 A 股等权/中位数、策略可投池等权。当前“业绩基准=前期流动性前100等权”和“安全基准=sh510300”用途不同，不能混成一个信号。

### P3：买入质量 fail-closed

- calibration 为 unavailable/drifted 且 `p_win_lower=0` 时，不允许把 15 元 robust hurdle 当作普通 warning；至少进入 shadow 或更低暴露权限。
- 增加 `robust_profit / downside_cvar`、净边际收益/生命周期成本、前瞻 5/10/20 日 hit rate 的明细门控。不要仅因现金/持仓缺口而购买低证据候选。

### P4：补齐状态—因子 OOS 证据

- 补算至 2026-05-29 的每日或月度 PIT rank IC、ICIR、正 IC 比例、top-bottom spread，并按 `family × safety structural state × horizon` 输出。
- 采用 walk-forward + embargo，弱势样本不足时明确 `insufficient_sample`，禁止从 19 天或单次行情推出生产标准。

## 9. 最终判定

- 工程门：本次容量—持仓合同修复已通过既有 20 日全链与专项回归，并已合并主干。
- 研究门：`blocked`。
- 生产门：`blocked`。
- 对用户观察的判定：**“3月后又出现之前的问题”一半正确**。3 月第一段是市场共振，旧容量稀释缺陷没有复发；但 4 月后确实出现新的、已有历史影子的逻辑叠加——状态恢复过快、C 级低证据补买、post-entry failure 无交易权限及审计字段误导。应按 P0→P4 做受控消融，不能直接靠调阈值追这次样本。
